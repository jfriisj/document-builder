# Document Builder — Dokumentationspakke

Denne mappe er den rensede, godkendte handoff-pakke.

## Brug denne rækkefølge

1. `01_IMPLEMENTATIONSSPECIFIKATION.md`  
   Kanonisk kontrakt for implementationen.

2. `02_BESLUTNINGSREGISTER.md`  
   Kort liste over de endelige beslutninger.

3. `03_KONVERTERINGSPLAN_21_TEMPLATES.md`  
   Godkendt plan for konvertering af de 21 dokumenttyper.

4. `04_ACCEPTANCE_OG_KOMPATIBILITETSGATES.md`  
   Godkendte gates for templates, regression og release.

5. `05_WAYFINDER_HANDOFF_GODKENDT.md`  
   Formelt afsluttet Wayfinder-handoff.

6. `06_UX_REFERENCE.html`  
   Godkendt UX-reference. Ikke produktionskode.

7. `07_WORD_REFERENCE_TEMPLATES/`  
   De 21 Word-skabeloner plus indeks, som implementationen skal konvertere.

## Bevidst udeladt

Pakken indeholder ikke:

- tracker.json,
- Wayfinder tracker-index,
- gamle map-snapshots,
- åbne/stale tickets,
- dubletter,
- research-noter med mellemkonklusioner,
- obsolete formuleringer som senere beslutninger har erstattet.

Hvis dokumenter er uenige, er `01_IMPLEMENTATIONSSPECIFIKATION.md` autoritativ.
